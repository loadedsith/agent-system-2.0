It supersedes the plugin's `newdle-seo-audit`. `skills/seo-audit/SKILL.md` drives `bun skills/seo-audit/scripts/audit.ts --url <u>` (zero npm dependencies; Chrome over CDP and `npx lighthouse@13.5.0`). Every request the skill makes, its own fetches included, goes through a guard proxy that connects only to the addresses it checked, so a host that re-resolves to a private, loopback, link-local or metadata address is refused unless `--allow-local` names the origin (metadata stays refused even then); a response the proxy itself generates is never recorded as the site's. It writes evidence.json, findings.json and report.md under `${TMPDIR:-/tmp}/seo-audit/`, and every file it writes (recordings and the LHR included) goes through one open (`writeContained` in `scripts/lib/report.ts`) that refuses a path inside `--repo`, a symlink in any component (`O_NOFOLLOW_ANY` on darwin; on Linux a `/proc/self/fd` re-check, where an ancestor swapped mid-write can still leave an empty file but never truncates or writes one) and a file with another hard link. The catalogue (`references/rules.md`, 186 rules: 164 mechanical, 22 judgment; `do-not-flag.md`, 83 myths; `frameworks.md`) admits a row only with a primary-source URL listed in `references/sources.md` and a quote found verbatim in a shipped research file; `test/catalogue.test.ts` enforces it. Five rule families (`scripts/rules/*.ts`) are tested offline against loopback fixtures with recorded Chrome, Lighthouse and CrUX evidence: every mechanical rule is planted and found, every judgment rule has a plant and a silent control, and the seven `control-*` fixtures yield zero findings (`test/coverage.test.ts`). Lab metric values and field data are proved in recorded mode only, since a live Lighthouse value varies run to run (perf-lab's LCP read 62.6 s on one run and 0.9 s on the next). A defect repeated once per sitemap entry for one root cause (a hit's `cause`: one foreign host, one bad `<lastmod>` form) is one finding with a count and five sample locators, so a 50,000-entry sitemap cannot bury the report. Loopback-only flags: `--chrome-no-sandbox` (Jo, `q-mv5ow6pae1fsow`: fixtures-only, since Chrome renders inside the lane fence only without its own sandbox) and `--chrome-trust-spki` (TLS fixtures); while either is on, the proxy refuses every non-loopback destination.
