**Defect** (root cause `~/agent-scratch/agent-system-2.0/paste-drop/ROOT-CAUSE.md`). `surface/extensions/surface-input.ts` linked OMP's `input` event (fired at submit) to `before_agent_start` (fired at dequeue) through one slot, `s.typed: string | null` in `surface/src/session.ts`. A second submit, or any other turn, between the two overwrote or cleared it, and `joInputRow` then returned silently on `typed === null || typed.trim() !== text`: no row, no echo, no warning. In the 2026-10-12T20-29 session 3 of 51 Jo messages were never echoed (both pastes plus `e 52 approve, 53 approve`), all three of them steers (16 steers in total). Jo's rule (ledger input `in-mv64ibt8qvuzuo`): an entry no turn took is warned about and discarded; an ambiguous match is warned, never guessed; text Jo did not type is never attributed to Jo.

**Design (PLAN D1-D5, D4a).**

- **D1, FIFO.** `SurfaceSession.typed` becomes `{ text, seq, source }[]` in submission order. An `input` from source interactive or rpc pushes with `seq = ++s.typedSeq`; any other source pushes nothing and no longer clears anything. `before_agent_start` sets `s.startSeq = s.typedSeq` before its take, so an entry was pushed before the latest turn started exactly when `seq <= startSeq`. `s.discarded` keeps the last 20 discarded texts, used only to warn, never to write a row.
- **D2, take rules.** `takeTyped(s, text)` lists (a) each entry whose trimmed text equals the trimmed prompt and (b) each contiguous run of 2 or more entries whose `"\n\n"`-join, trimmed, equals the prompt. Only (a), same text: the oldest is removed (`one`). Only (b), exactly one run: removed (`joined`). (a) and (b) together, or more than one distinct (b) run: ambiguous, nothing taken, no row, one warning (`this prompt matches more than one way Jo's typed messages could have been delivered; no input row: re-send it`). No candidate: null. A command turn takes only its own entry. `joTyped = take?.kind === "one"`, the same name and meaning as PR #68's; `joInputRow(s, ctx, body, joTyped: boolean, ledger)` takes #68's boolean form, and `joTyped` false still returns silently for prompts Jo did not type (continuation, aside, `omp -p`).
- **D3, joined text is split exactly or warned.** On the prose path a `joined` take calls `joInputRow` once per typed entry, in order, with that entry's trimmed text: one input row, one `surface-jo-input` entry and one canonical singular `Jo's words above are input in-…` echo per message, as two separate turns would give. Never one merged Jo row, no plural marker. On a command path the commands run as today, `joTyped` is false, and one warning says N messages arrived joined (OMP `steeringMode` `all`) and none got an input row.
- **D4, a miss is loud; an untaken entry is discarded.** At a prose take of entry k (or a joined run starting at k) every older entry still in the FIFO is discarded at once, before the turn's own row, so no later prompt in the same run can take it; a command turn removes only its own entry. Entries no newer take passes are removed by `sweepTyped`, which acts only when `ctx.isIdle()` is true and `ctx.hasPendingMessages()` is false, on entries with `seq <= startSeq`; triggers are `agent_end` (deferred one macrotask) and the top of every `input` handler. A removed entry is judged: silent only for TUI `!cmd` / `!!cmd` and `$ code` / `$$ code` entries (OMP runs them locally by prefix, `input-controller.ts` on OMP 18.8.6); a `/…` entry gets a softer `info` warning, also a model notice, **quoting only the command name, never its arguments** (`/login <code>` and `/mcp add … --token <t>` arguments are kept out of OMP history and must not reach a session entry or the model); every other entry gets a `warning` notify to Jo plus a `surface-input` model notice with its first 8 words. A later prompt that equals a discarded text and takes no entry gets no row and one more warning; `s.discarded` never produces a row.
- **D4a, types and fake host.** `surface/src/types.ts` `Ctx` gains optional `hasPendingMessages?(): boolean` beside `isIdle` (absent means not known idle, so the sweep does nothing); `surface/test/helpers.ts` `ctxOf` gains controllable `isIdle` / `hasPendingMessages`.
- **D5.** The `surface-input.ts` header paragraph and the `session.ts` field doc describe the FIFO, the joined case and the warning. The fail-closed rule stays: a miss writes no row, and now says so.

**steeringMode finding.** OMP 18.8.6 `steeringMode` / `followUpMode` are `all` or `one-at-a-time`, default `one-at-a-time` (`src/modes/settings.ts`); neither `~/.omp/profiles/agent-system-2/agent/config.yml` nor `~/.omp/agent/config.yml` sets either. `all` can still reach as2 through the TUI settings panel (Interaction, Input) or an RPC `set_steering_mode`. Under `all`, `#prepareQueuedUserMessages` joins the queued user texts with `"\n\n"` into one `before_agent_start` prompt; D2(b) and D3 split that exactly or warn.

**Tradeoffs.**

- Only TUI `!cmd` and `$ code` entries are dropped silently; every `/…` entry a turn skips gets a softer warning, because an unknown slash command is a prompt. Each `/model` used before a later turn costs one info line.
- An entry older than the one a prose turn takes is discarded at that take: a follow-up Jo queued and then overtook with a steer, or a direct prompt still in OMP's preflight, arrives with no row and is warned twice instead of getting its row late. Keeping it would let a later identical prompt take Jo's receipt.
- Jo's text is kept as typed, so text is the key (OMP gives extensions no per-submission id). An entry still waiting, or skipped only by a command turn, can be taken by an identical untyped prompt until the next prose take or idle point, the same text check main makes today. Closing it would mean rewriting Jo's text with a nonce OMP then stores and shows; not taken.
- A submission OMP refuses before any turn (RPC `cancelled`/`local`) is warned only after a later turn, never if none comes: the extension API has no refusal event, and OMP answers the sender.
- Joined text on a command path writes no rows and warns, rather than guessing which lines were prose.
- A message sent with OMP's queue shorthand (`-> text`, `=> text`, `/queue text`) reaches the turn without its prefix, and OMP may split a numbered list into several prompts (`pi-tui/src/prompt/queue-input.ts`), so it gets the miss warning (or the `/queue` info line), never silence and never a row under other words.
